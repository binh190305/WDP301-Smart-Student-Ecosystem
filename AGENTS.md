# AGENTS – Project‑wide Constraints for Smart Student Ecosystem (STE)

These constraints are **mandatory** for every agent, skill, and automated action operating on this repository. Violations will be flagged during verification.

- Do **not** rebuild, delete, or overwrite existing application source code.
- Do **not** modify the database schema or production data structures.
- Do **not** add or remove dependencies unless explicitly approved by a stakeholder.
- Do **not** introduce features that contradict the documented business rules (e.g., automatic team assignment, real‑time chat).
- All changes must be **reviewable**, **testable**, and **documented**.
- Any unknown information must be marked **TBD** and escalated for clarification.
- Agents must respect the **security** and **privacy** rules defined in `.agents/rules/security.md`.
- Follow the **coding standards**, **testing**, and **AI‑development** guidelines defined in the respective rule files.

> **NOTE**: These constraints are enforced by the Antigravity rule engine. Any attempt to bypass them will be rejected.
